# Gopal Sarkar — Professional Portfolio

A responsive, single-page portfolio for **Gopal Sarkar**, an AutoCAD Designer with 17 years of experience and additional experience with MapInfo and design applications.

## What's included
- Responsive layout for desktop, tablet, and mobile
- CAD-inspired visual style with custom SVG technical illustrations
- About, expertise, capability examples, workflow, and contact sections
- Facebook and GitHub profile links
- Accessible mobile navigation and reduced-motion support
- No build step or external framework required

## Preview locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Open the repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under the build/deployment settings, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
5. Wait for the deployment to finish; GitHub will show the published URL in Pages settings.

See the [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

Replace the illustrative capability graphics with your real project screenshots or drawing samples, and add any additional software names, certifications, or contact details you would like to publish.
